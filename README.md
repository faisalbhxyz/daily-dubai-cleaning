# Daily Dubai Cleaning

Next.js homepage inspired by [Royal Gloss Cleaning](https://royalglosscleaningrak.com/), built for Dubai cleaning services.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- SEO metadata + LocalBusiness JSON-LD

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Update contact details in `src/lib/site.ts`.
